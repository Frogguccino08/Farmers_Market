# Farmer's Market

Este projeto é o meu primeiro mod feito para o jogo Minecraft 1.20.1, baseado no mod da Youtuber luxintrus "Heliothopic".

Ele adiciona três novas armas ao jogo:
- Foice, que tem funcionalidade de enxada e de espada e permite fazer um ataque em área em volta do jogador.
- Girassol comicamente grande, com knockback elevado e que causa nausea.
- Espada de raiz de flor, que causa o efeito wither e permite jogar o alvo para o ar.

Esse mod foi desenvolvido para botar em prática conceitos aprendidos em curso, seu desenvolvimento foi pausado por conta de trabalhos de graduação.
